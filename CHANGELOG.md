# Changelog

## [1.1.1] - 2026-11-02

### Fixed

- Restore the player's animation speed before another weapon skill starts. Overlapping accelerated reloads from both shotgun mods could otherwise leave animations running too fast.

## [1.1.0] - 2026-11-01

### Added

- AmmoMode 3: shoot without reloading using a finite supply of loaded rounds and compatible inventory shells. The native HUD shows ∞/remaining ammo. Requested by life520.

## [1.0.0] - 2026-10-31

### Added

- Infinite reserve with the normal two-round reload. Configure this shotgun independently of ShotgunPlus.
- Per-weapon optional damage, reach and cooldown settings with native defaults.
- Host-controlled gameplay settings with live synchronization and a local native HUD display option.
